# Frontend Development Guidelines

> Frontend status for the EoH project.

---

## Overview

EoH is currently a backend-only Python project. This repository does not contain a frontend application, JavaScript or TypeScript toolchain, or frontend source tree.

The files in this directory are Trellis placeholders only. They are not active project guidelines until a real frontend codebase is added.

When a frontend is introduced:
